# AS Atomic Content

AlphaSys WordPress plugin for ACF-backed Cards and Rows alongside native WordPress Patterns.

Install from the root-level `as-atomic-content.zip`, or build a fresh archive with `scripts/build-plugin-zip.sh`. WordPress 6.3 or later is required; ACF 6.1 or later is required for Cards, Rows, and legacy Pattern migration. Activation or update copies legacy Patterns as native unsynced patterns without deleting their sources. See [plugin documentation](as-atomic-content/readme.md) for behaviour and compatibility notes.
