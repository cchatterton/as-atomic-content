Patterns — How to use them

A Pattern gives an editor a prepared arrangement of blocks. Use it while editing a page or template, then check whether it is synced or unsynced before changing its contents.

Insert a Pattern

  1. Open the page or template in the WordPress block editor.
  2. Open the block inserter, choose Patterns, and browse or search for the layout you need. Categories can help narrow the list.
  3. Insert the Pattern at the intended place and preview the full page.

After inserting

For an unsynced Pattern, replace sample copy, images, and links in this page's copy. For a synced Pattern, changes to its shared content can affect other placements. If the page needs a unique variation, check the editor's available options before changing a synced source.

Review the page

Check heading order, button destinations, image alt text, mobile layout, and any blocks that depend on the current page. A Pattern preview is a starting point; the final result can depend on the page's theme styles and surrounding blocks.

Manage the source

Use Atoms > Patterns to find, create, and edit native Patterns. WordPress's Block Patterns guide describes the native editor workflow.
