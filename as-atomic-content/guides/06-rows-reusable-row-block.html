Rows — Reusable Row Block

A Row stores a section made from blocks so the same section can appear in more than one place. The Row block places a published Row inside a page. Its placements use the shared source, so changing that Row can change all pages that show it.

Find or edit the source Row

  1. Open Atoms > Rows and search for a Row with the right purpose.
  2. Open it to edit its blocks, headings, images, and links. Note where it is already used before making a broad change.
  3. Publish or update it, then review representative pages that use it.

Place it with the Row block

In a page's block editor, add the site's Row block and choose a published Row. Preview the page before publishing. The Row block is supplied by the active site theme or another component, so its precise controls may vary between sites.

When to create a Row

Use a Row when a section is deliberately reused and should change everywhere together, such as an approved call to action. Do not create a new Row for ordinary one-off page content. A page-specific Row can be justified when a wrapper or controlled site structure requires it; give that exception a clear name.

Context and review

Some blocks inside a Row can depend on the page where the Row appears. Test those Rows on each relevant page type. Check mobile layout and links as well as the Row editor preview, because the surrounding page can affect the result.
