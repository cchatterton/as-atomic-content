Patterns — Categories

Pattern Categories organise native WordPress Patterns so editors can find them in the Site Editor and block inserter. A category is a label for browsing; it does not change whether a Pattern is synced.

Create or manage categories

Open Settings > Pattern Categories to create, rename, or remove categories. The Count column shows how many Patterns are assigned to each one. Access depends on your WordPress permissions.

Assign a category to a Pattern

  1. Open the Pattern from Atoms > Patterns.
  2. Expand Pattern Categories in the settings panel.
  3. Type a category name and press Enter or comma until it appears as a category chip. This step also creates a new term when permitted.
  4. Click Save and reopen the Pattern to confirm the assignment.

If a new category does not save

Text left in the input is not assigned. Press Enter or comma so the chip appears before saving. If the term already exists, select the existing suggestion. If you lack permission to create terms, ask a user with access to Settings > Pattern Categories to create it first.
