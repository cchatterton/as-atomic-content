Rows — Post Type Wrappers

Post type wrappers place reusable Rows at named positions around every item of a post type. They are configured from that post type's Edit Wrappers screen, not from an individual post. For example, Pages > Edit Wrappers opens the Page Wrappers screen.

Choose a wrapper position

  1. Open the relevant post type menu and choose Edit Wrappers. For Pages, use Pages > Edit Wrappers.
  2. Choose a position tab. The Page Wrappers screen includes positions such as Before Content, After Content, Before Hero, and After Footer. Available positions can differ by post type.
  3. Under Reusable Rows, click Add Row, then choose the published Row in the new Row field. Add another entry if that position needs more than one Row.
  4. Save or update the wrapper screen, then check a representative item of that post type to confirm the Rows appear in the intended position and order.

Change the Row itself

The wrapper screen chooses which Rows appear at each position and in what order. To change a Row's actual blocks, open it under Atoms > Rows. A Row may also be used elsewhere, so review its other placements before changing shared content.

Scope of a change

Changing a wrapper assignment can change every item of that post type. Editing the shared Row can affect every place that uses it, including other wrappers and Row blocks. Review representative items after either change, including items with different content lengths. A Row block placed directly in one post is a separate placement from these post type wrapper settings.
