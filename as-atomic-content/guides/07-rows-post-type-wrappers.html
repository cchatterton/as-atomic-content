Rows — Post Type Wrappers

A post type wrapper is a site-level way to place a shared Row around or alongside content of a particular post type. Instead of adding a Row block to every post, the site's theme or template selects the Row as part of rendering that post type. The wrapper setup is outside this plugin; Atoms stores the Row it refers to.

How to recognise a wrapper

If the same section appears on many posts but there is no Row block in the individual post editor, it may come from a post type wrapper. Check the relevant template or ask the site team which Row it calls before editing. Do not add another Row block to the post until you know whether that would duplicate the section.

Edit the Row used by a wrapper

  1. Identify the Row selected for the post type in the site's wrapper or template configuration.
  2. Open that Row under Atoms > Rows and change its blocks.
  3. Review several posts of that type, including posts with missing fields and different content lengths, before treating the change as complete.

Context and impact

A wrapper may provide layout and post context around the Row. Its exact placement and settings depend on the theme. A change to the shared Row can affect every post using that wrapper; a change to wrapper configuration can affect the whole post type. Check the full rendered page, not only the Row editor.
