Rows — Post Type Wrappers

Post type wrappers place reusable Rows at named positions around the content of a post type. For example, About-us > Edit Wrappers opens the About-us Wrappers screen. Its tabs include positions such as Before Content and After Content, each with a Reusable Rows field. The available positions can differ by post type.

Choose a wrapper position

  1. Open the relevant post type menu and choose Edit Wrappers.
  2. Select the tab for the position where the Row should appear, such as Before Content or After Content.
  3. Use Reusable Rows to select the Row for that position, then save the wrapper settings.
  4. Check a representative post of that type to confirm the Row appears in the intended place.

Change the Row itself

The wrapper screen chooses where a Row appears. To change its actual blocks, open the selected Row under Atoms > Rows. A Row may also be used elsewhere, so review its other placements before changing shared content.

Scope of a change

Changing the Rows assigned to a wrapper position can change that position across the post type. Editing the shared Row can affect every place that uses it. Review representative posts after either change, including posts with different content lengths. A Row block placed directly in one post is a separate placement from these post type wrapper settings.
