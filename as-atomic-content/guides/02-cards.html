Cards

A Card is a micro template. Its Card Markup field holds the HTML structure for one item; the rendering block supplies the changing content. A shared Card keeps repeated items visually consistent across the site.

Create a Card

  1. Open Atoms > Cards and add a Card with a clear, descriptive title.
  2. Put the reusable HTML in Card Markup. Use the placeholder syntax expected by the block that will render it.
  3. Publish the Card, then test it in a page before using it widely.

The Card is a template, not a page section by itself. The plugin stores the Card post type and ACF field; site blocks and theme rendering code decide how it appears.

Use a Card with AlphaBlock

AlphaBlock selects posts, then renders each result through the chosen Card template. In a page, add an AlphaBlock, configure its query and filters, select Card in Show Posts, and choose a published Card. Preview with real content, including missing fields and long titles. AlphaBlock also has a List mode; List mode does not use a Card template.

Use a Card with AlphaCard

AlphaCard is for content entered at the point of use. Add the AlphaCard block, add a Card row, select a published Card, and fill in the discovered merge-token fields. You can add several Card rows and reorder them. Use Get merge tokens if you change the selected Card and need to refresh its fields.

AlphaCard does not fetch a post or ACF field for a token such as %%$post->post_title%%; in AlphaCard it is the name of an input that the editor fills. See Merge tokens for the distinction.

What happens when you edit a Card?

Changing shared Card Markup can alter every place that renders that Card. Review representative pages and mobile layouts after a template change. A new Card is appropriate when the structure or design differs; a new Card for every item defeats the shared-template benefit.
