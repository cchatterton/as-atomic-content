Patterns — Sync vs Unsync

WordPress Patterns can be synced or unsynced. This setting decides what happens to existing placements when the source Pattern changes.

Unsynced Patterns

An unsynced Pattern supplies a starting copy of its blocks. After insertion, the page editor can change that copy without changing the original Pattern or copies on other pages. Editing the source Pattern later does not update copies already inserted. Use this when the layout should be reusable but each page needs its own wording or imagery.

Synced Patterns

A synced Pattern stays connected to its source. Editing the shared Pattern can update every placement. Use this when the same content and layout should stay consistent across the site. Before changing one, review where it appears and check representative placements afterwards.

Check the status before editing

In Atoms > Patterns, the list shows each Pattern's sync status. Open a Pattern to inspect or change it. The WordPress editor may label the two states Synced and Not synced. Do not assume a Pattern is unsynced because its content looks editable on a page.

Source versus placement

If you want to change one page only, first check whether the inserted Pattern is synced. If you want a change everywhere, verify that every intended placement really uses the same synced Pattern. For an unsynced Pattern, each inserted copy is its own page content after insertion.
