Choose the right Atom

Start with the change you expect to make later. The best choice is the one whose update behaviour matches that change.

Decision guide

NeedChooseWhy
One item layout repeated for many posts.CardOne markup template can render different items consistently.
A section shared across pages, with source edits reflected everywhere.RowPlacements refer to the reusable Row.
A layout editors can insert and then customise independently.Unsynced PatternEach inserted copy can be edited for its page.
Ordinary content used on just one page.Page blocksNo shared component is needed.

Before creating something new

  1. Search existing Cards, Rows, and Patterns for a close match.
  2. Decide whether the new content should change everywhere or only at its insertion point.
  3. Give a reusable component a purpose-based name so another editor can find it.
  4. Test with representative content and check the mobile layout.
