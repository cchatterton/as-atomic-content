Our Composable Atoms

Our site is assembled from reusable content, values, styles, and code. We call these composable atoms: parts that can be combined into a page and maintained at their source. The Atoms admin menu groups Cards, Rows, and Patterns, but it is only one part of this wider system.

Content and layout

Cards, Rows, and Patterns help editors compose visible content. Check whether a part is shared or copied before changing it on an existing page.

Cards

A Card is a micro template: HTML in the Card Markup field for one item. AlphaBlock can use a Card to display queried posts; AlphaCard can use one with values entered in the page editor. Changing the shared Card markup can change every placement that uses it, while each placement can still supply different content.

Rows

A Row is a reusable section built from blocks. A Row block can place it in an individual post, while a post type's Edit Wrappers screen can assign it to a named position across that post type. Both placements refer to the same Row source, so an edit to the Row can affect all of them. Rows are normally for sections used more than once, with occasional justified exceptions for controlled page structures.

Patterns

Patterns are native WordPress arrangements of blocks. An unsynced Pattern supplies a starting copy that editors can change independently after insertion. A synced Pattern stays linked to its source and updates across placements. Check its sync status before changing a Pattern that is already in use.

Shared values and colours

List of Values (LOV) manages named values that site components can reuse. Palette, provided by TN Pallet, manages named colours and generates colour utilities for use across the site. Updating a shared value or colour can change multiple components without editing each placement.

Local CSS and JavaScript

Local CSS holds site-specific styling rules, while custom JavaScript snippets supply behaviour where needed. These can support Cards, Rows, Patterns, and other parts of the site. Their scope and delivery settings matter: a change may affect one target or many pages.

Where to find them

  • Atoms > Cards lists Card templates.
  • Atoms > Rows lists reusable Rows.
  • Atoms > Patterns opens the native WordPress pattern manager.
  • Settings > List of Values (LOV) manages shared lists and values.
  • Appearance > Palette manages the named colour system.
  • Local CSS manages custom CSS and JavaScript snippets.

When editing an existing site, identify the source of the part you see and check where else it is used. That tells you whether to update one placement or the shared source.
