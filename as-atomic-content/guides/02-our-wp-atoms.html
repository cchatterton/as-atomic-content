Our WP Atoms — Cards, Rows and Patterns

The Atoms menu is the place to manage three kinds of building block already used on this WordPress site. When editing an existing page, identify which kind supplies the part you want to change before editing its source.

Cards

A Card is a micro template: HTML in the Card Markup field for one item. AlphaBlock can use a Card to display queried posts; AlphaCard can use one with values entered in the page editor. Changing the shared Card markup can change every placement that uses it, while each placement can still supply different content.

Rows

A Row is a reusable section built from blocks. A Row block or a site wrapper can place that section on a page. Its placements refer to the same Row source, so an edit to the Row can affect all of them. Rows are normally for sections used more than once, with occasional justified exceptions for controlled page structures.

Patterns

Patterns are native WordPress arrangements of blocks. An unsynced Pattern supplies a starting copy that editors can change independently after insertion. A synced Pattern stays linked to its source and updates across placements. Check its sync status before changing a Pattern that is already in use.

Where to find them

  • Atoms > Cards lists Card templates.
  • Atoms > Rows lists reusable Rows.
  • Atoms > Patterns opens the native WordPress pattern manager.
