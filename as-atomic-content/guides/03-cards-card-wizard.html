Cards — Card Wizard

The Card Wizard is a helper on the Card editing screen where the site theme provides it. It helps assemble markup and class names for Card Markup. The Wizard does not create a separate Card or replace the need to save the Card post.

Open a Card

  1. Open Atoms > Cards and choose an existing Card.
  2. Find the Card Wizard panel and the Card Markup field.
  3. Work on a duplicate or draft when changing a heavily used Card. A saved markup change may appear anywhere that Card is rendered.

What the Wizard tabs do

  • Palette helps choose a configured colour and generates a text, border, or background class. Hover and alpha options are available where the site palette supports them.
  • Grid generates a starting grid structure from rows, columns, and gap choices. Replace its sample cells with the content and Echo tokens the Card needs.
  • Utility lists available layout and palette class names for reference.
  • Echo lists examples of placeholders that the site's Card renderer can fill from post or field data.

Finish and check

Copy the generated class or grid markup into Card Markup, adapt it for the actual Card, and save the Card. Check it in a real AlphaBlock or AlphaCard placement. Confirm images, links, long text, and mobile layout. The post slug may also be used by rendering code, so avoid changing it casually on an established Card.

If the Card Wizard is absent, the site may still render Cards: the Wizard belongs to the site's theme or another component, while this plugin provides the Card post type and Markup field.
