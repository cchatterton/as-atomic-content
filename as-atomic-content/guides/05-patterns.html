WordPress Patterns

A Pattern is a ready-made arrangement of blocks. Editors insert it into a page to start with an approved structure, then replace the sample content. Atoms uses WordPress's native pattern system.

Find and insert a Pattern

  1. Open Atoms > Patterns to browse and manage patterns.
  2. In a page or template editor, open the block inserter and choose a Pattern.
  3. Replace its sample copy, images, and links, then review the page at desktop and mobile widths.

Unsynced and synced

An unsynced Pattern is a starting copy. After insertion, editing that page's copy does not change other uses, and editing the source Pattern does not update copies already inserted. This is the default for the legacy Patterns migrated by AS Atomic Content.

A synced Pattern remains linked across placements; changes to it can affect every use. Choose it only when shared updates are intended. Use a Row for the established site Row workflow.

Pattern Categories

Open Settings > Pattern Categories to create, rename, or remove categories. To assign a category in a Pattern, expand Pattern Categories, type its name, press Enter or comma so it becomes a chip, then click Save. Text left in the input has not been assigned. The manager's Count column shows how many Patterns use a category.
