Atoms gives the site a shared design system. Build a component once, place it where it is needed, and update the source when a site-wide change is required. Cards, Rows, and Patterns solve different sizes of content problem.

The three building blocks

TypeWhat it holdsUse it when
CardA small markup template for one item.Many items should share the same presentation, with different content filled in.
RowA reusable section of blocks.The same section should appear in several places and change everywhere together.
PatternA ready-made arrangement of native blocks.Editors need a starting layout they can insert and then change independently.

How they fit together

A Card is the smallest template. A Row can contain blocks that render Cards or other content. A Pattern can give an editor a starting arrangement of blocks, including site-specific blocks where available. These are choices at different levels; one does not replace the others.

Start with Choose the right Atom if you are deciding which type to create. For the practical steps, open the Cards, Rows, or Patterns guide.

Where to go in WordPress

  • Atoms > Cards manages Card templates.
  • Atoms > Rows manages reusable Rows.
  • Atoms > Patterns opens WordPress's native pattern manager.
  • Settings > Pattern Categories creates and organises pattern categories.
