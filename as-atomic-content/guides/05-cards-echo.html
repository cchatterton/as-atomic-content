Cards — Echo merge tokens

Echo tokens are placeholders inside Card Markup, wrapped in double percent signs: %%...%%. The site's Card renderer replaces supported tokens with values from the item being displayed. This lets one Card layout show different posts without copying its markup.

Common Echo tokens

ExampleWhat it requests
%%$post->post_title%%The displayed post's title.
%%$post->post_excerpt%%The displayed post's excerpt.
%%$post->ID%%The displayed post's ID.
%%$acf->meta_key%%An ACF field; replace meta_key with its real field name.
%%$meta->meta_key%%A stored post meta value with that key.
%%$image->featured%%The displayed post's featured image, where supported.

Use a token in markup

For example, <h3>%%$post->post_title%%</h3> creates a heading using the current item's title. Use a real field name for ACF or meta tokens, and preview with a post that has that field populated. A missing value can leave an empty space in the Card.

What changes in AlphaCard?

AlphaCard scans the selected Card for %%...%% placeholders and creates editor inputs. In AlphaCard, even %%$post->post_title%% is an input name: it does not fetch the current post title. Enter a value for each placeholder in the AlphaCard block, and use Get merge tokens after changing its Card selection. In AlphaBlock's Card mode, the Card renderer supplies values from each queried post.

Check the output

Preview the Card with real content and review empty fields, escaping, links, and images. Echo's double-percent Card placeholders are different from AlphaBlock's single-percent query context tokens such as %me%; a query token belongs in a block setting, not in Card Markup.
