Cards — Utility Classes

Utility classes are short CSS class names that apply one reusable styling rule. In Card Markup they keep spacing, colour, and layout choices consistent with the site. The available classes come from the active theme and palette, so use the Card Wizard's Utility and Palette tabs as the site's current reference.

Colour classes

Configured palette colours can provide classes such as text-{name}, border-{name}, and background-{name}. Hover variants use names such as hover-background-{name}. Alpha variants may add -10 through -90 for transparency. Replace {name} with a colour actually listed in the Wizard; a guessed class may have no styling.

Layout and presentation classes

The Wizard's Utility tab also lists site classes for spacing, borders, alignment, typography, images, and line clamping. Examples include padding-sm, gap-md, border-radius-sm, align-flex-center, and clamp-2. Confirm the exact name and behaviour on the current site before using it.

Put classes in Card Markup

Add classes to the relevant HTML element, for example <div class="padding-sm background-light-1">...</div>. Keep the element's purpose and accessible text intact. A class changes appearance; it does not supply the Card's content. Save the Card, then preview it where it is used at desktop and mobile widths.

When a class is missing

If a class appears in markup but has no effect, check its spelling against the Wizard and confirm the configured palette colour exists. Theme or palette changes can affect both the editor preview and the front end. Ask the site team before adding a one-off style to a shared Card.
