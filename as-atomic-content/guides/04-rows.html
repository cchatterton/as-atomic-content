Reusable Rows

A Row is a reusable site section made from blocks. Create one when the same section is needed in multiple places and a change to its source should affect those placements. This is the main site-wide reuse idea behind the Atoms design system.

Create a Row

  1. Open Atoms > Rows and give the Row a name that describes its purpose.
  2. Build the section in the block editor. Check headings, links, responsive layout, and any blocks that depend on the current page.
  3. Publish it, then place it on a test page and verify how it renders in context.

Place a Row

On sites with the Row block, add that block to a page and choose the published Row. A theme or template can also call a Row through a wrapper. Both methods refer to the shared Row source; the exact block and wrapper controls are provided by the active theme, not by this plugin.

When a Row relies on its host page for context, test it on each type of page where it will appear. A wrapper may add layout or context around the Row, so review the complete page rather than the Row editor alone.

When should a Row be reusable?

Prefer a Row for an approved section that repeats across several pages, such as a shared call to action or related-content section. Editing the Row should then update those uses together. Do not create a Row for ordinary one-off page content. An exception can be justified when a page-specific section needs a wrapper or a controlled structure that the page editor cannot provide directly; name and document that exception.

Review changes before publishing

Because a Row is shared, a small edit can have a broad effect. Check representative placements, particularly pages with different content or relationships, before and after changing a heavily used Row. If two placements need different structures, consider separate Rows rather than adding hidden assumptions to one.
