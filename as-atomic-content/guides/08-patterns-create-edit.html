Patterns — Create & edit

Patterns are native WordPress arrangements of blocks. Create one when editors need a repeatable starting layout or a section linked across placements. An existing Pattern can be edited in the Site Editor; check its sync status before changing its blocks.

Create a Pattern

  1. Open Atoms > Patterns and choose Add Pattern, or select blocks in an editor and use WordPress's create-pattern action.
  2. Give it a name people can recognise and choose whether it should be synced.
  3. Build the blocks, replace placeholder content as appropriate, and save.

Edit an existing Pattern

Open it from the Patterns screen, change the blocks, then click Save. If it is synced, the change can appear everywhere the Pattern is used. If it is unsynced, existing inserted copies remain independent. Review an actual placement after editing, particularly for spacing, text colour, and buttons.

Patterns migrated from the old Atoms type

Legacy Atoms Pattern posts were copied into native WordPress Patterns as Not synced. Their old source posts were retained for recovery. The native copy is the Pattern to manage from the Atoms menu.
